# 知栖小商店与特效装扮

商店位于陪伴手账的“小商店”页。共16件样式：4件默认样式与12件金币商品。点击“预览”免费试穿，预览区和商店面板一起显示搭配；离开商店恢复已装备主题，“还原已装备”清除试穿。点击“兑换”才扣金币并立即装备，已拥有的物品再次装备免费。

## 金币保存与本地维护

余额必须与全部金币流水一致，购买、出售与赠送保存后才发布；重复购买已拥有商品不重复扣费。原存档和上一份备份保留。普通新用户仍从0金币开始，不会在每次启动或升级时收到体验金币。

仅供明确授权的本地维护，在退出知栖后运行：

```powershell
node scripts/grant-coins.cjs 1000 unique-request-reference "装扮体验赠送"
```

赠送有单独流水，不伪造水果出售、浇水或收获。唯一请求编号防止重试时重复赠送；相同编号配不同金额或说明会拒绝。渲染器和公开IPC不能调用赠送方法。操作前备份本地存档，完成后启动支持赠送流水的0.1.12及后续版本。
