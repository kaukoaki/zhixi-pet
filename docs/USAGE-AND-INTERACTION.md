# 知栖的 Codex 余量与鼠标交互

名字取“知意而栖”，结合 GPT 的知识与桌边小伙伴的陪伴。界面名称、托盘、任务提示和新启动入口均为「知栖」；内部应用 ID、用户数据路径和素材文件名继续兼容旧版。

## 查看余量

- 单击角色：等待系统双击判断间隔后，显示小漫画气泡。
- 双击角色：直接打开任务弹窗，不先弹出余量。
- 右键 → 查看额度：菜单直接列出已读取的窗口余量，可查看详情或刷新。
- 右键 → 偏好与动作管理：直接进入动作管理。
- 用量气泡点击空白处、按 Escape 或点击 × 收起。
- 角色聚焦后 Enter / Space 查看用量；Ctrl + Enter 打开任务。

应用使用本机已登录的 Codex CLI，运行短生命周期的 `codex app-server --listen stdio://`，初始化后仅调用 `account/read` 与 `account/rateLimits/read`。无需提供 API Key，也不读取或复制登录凭据。不创建线程、执行模型推理、消费重置次数或购买点数。显示的是本机 CLI 登录的账号，若桌面应用使用另一账号，需先同步本机 CLI 的登录。

优先展示 `rateLimitsByLimitId`，无可用分桶时回退到 `rateLimits`。剩余比例是 `100 - usedPercent`，裁剪到 0–100。窗口名称按服务返回时长计算，300 分钟为五小时，10080 分钟为每周；未知时长、比例、重置时间显示未提供。到重置时间后提示刷新，避免从本地时钟推断余量已恢复。

订阅名称来自当前账号 `planType`，支持 Plus、Pro、Pro Lite、Pro Max 及其他已知订阅；未知标识如实显示。展示层按用户偏好简化：Plus 保留实际五小时与周窗口；Pro 系列仅显示时长为 10080 分钟的实际周额度，无周窗口则提示暂未提供，不用五小时或满额替代。服务原始数据保持完整，其他套餐仍显示实际返回的窗口。预设套餐说明已移除，避免日后规则变化导致误导。API Key 和其他登录方式显示专门说明，不冒充 Plus / Pro 用量。

打开详情或右键菜单时刷新，用量气泡可见时每分钟刷新，隐藏后不轮询。60 秒内复用结果，手动刷新跳过缓存，并发刷新合并为一次请求。查询最多 15 秒；失败清空旧账号余量并显示重试提示，自动读取的失败重试间隔为 15 秒。查询在退出时取消。数据只保存在内存，前端不接收邮箱、凭据或原始服务响应。

协议来源：[官方 app-server 账号与额度接口](https://learn.chatgpt.com/docs/app-server)。生成的本机协议检查记录在 `.cache/usage-schema`，不包含账号凭据。

## 鼠标判定

使用屏幕坐标计算相对按下位置的欧氏距离，达到 7 像素才进入拖动。小范围往返抖动不会累计成拖动；真正进入拖动后，即使回到原点也不会触发单击。开始拖动时即播放提起反应，移动时保持原有窗口尺寸，松手恢复放回动画。

双击间隔只读 Windows `HKCU\Control Panel\Mouse\DoubleClickSpeed`，无法读取时使用 500 毫秒。单击等待这一间隔，第二次点击会取消待定单击；第二次按下后拖动、右键、长按超过 650 毫秒、失焦、失去捕获或按钮状态丢失都会取消待定单击。非主指针不接管当前拖动。

验证包含 Plus / Pro / 多模型窗口、缺失数据、API Key 登录、只读 RPC、失败清理与并发缓存，以及抖动、拖回原点、双击、长按、取消和拖动尺寸稳定性。界面使用独立窗口和分区，人物缩放不会放大用量面板。

## 浅色弹窗与余额动作

任务弹窗 352 × 352，额度气泡宽 288、高度随内容自动收缩。使用奶白、淡紫和薄荷绿的圆润样式，删除英文装饰、冗长套餐说明与额外点数。额度页只保留订阅徽标、剩余比例、进度条与简短重置时间，点右下角 ↻ 主动查询。右键和托盘恢复系统原生菜单，动作分类与钱包入口保留。后台结果同步更新额度页、任务页订阅徽标和原生菜单的数据源。

「余额」分类现有五个动作：查看钱包、省着点用、只剩一点点、空空的、等一会就好。查询打开用量窗口或手动刷新时，等待实际额度结果，在已导入视频且无正在执行的任务时选择反应；自动轮询只刷新数字，不触发动画。五段均为 30 fps、10 秒透明视频，菜单可独立点播；全库 16 个非待机动作已装配。

默认阈值：>50% 普通查看，>20% 且 ≤50% 省着点用，>0% 且 ≤20% 只剩一点点，0% 空空的；0% 且所有耗尽窗口都将在未来 30 分钟内重置时，等一会就好。按页面展示规则取 Codex 总额度的最低剩余比例，Pro 系列只看周窗口。阈值属于本项目的动画偏好，不代表套餐政策；数据未知、过期、查询失败或没有总额度的多模型分桶时使用普通查看。未安装所选反应时回退普通查看，普通版也未安装则不播放。

关闭额度弹窗、拖动或新查询取消尚未播放的旧查询结果；任务从查询开始到返回期间启动时不打断任务动画。后台刷新绕过动画控制器。素材分类与可移植路径见 [目录规范](../actions/ASSET-LAYOUT.md)，独立待机、旧动作和个人设置保持兼容。

验收覆盖同一服务从 Plus 切到 Pro 时三处同步变化、移除旧 Plus 文案、实际窗口数量变化、原生菜单可用状态与 Pro 周额度筛选，以及钱包主动/后台触发区别。截图中的测试数值仅用于界面验收；正常启动不会读取测试数据。
