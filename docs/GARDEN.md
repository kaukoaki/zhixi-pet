# 知栖小花园与金币商店

打开陪伴手账，默认进入“小花园”。原来的日常小记与纪念卡继续保留。

## 种植和打卡

有 3 个种植位，番茄、草莓、西瓜种子均免费，可以自由搭配。种下后点击“浇水打卡”，为所有今天尚未浇水、未成熟的植物浇水。每个种植位一天最多增长一次，同一天重复打开、点按钮、收获再种都不能多算一个生长日。

植物累计浇水 10 个不同日期后成熟；漏打卡只暂停，不枯萎，不补记离线天数。成熟后点击“收获”放入收获箱，再选择出售。每份收获售价为 50–100 金币，在收获成功时确定并保存，不随刷新、重启或出售次数重抽。三种植物使用相同售价范围，可以按喜好种植。

三种植物分别在首次收获时解锁知栖纪念卡；只是成熟但没有收获不会提前解锁。已卖出的收获依然保留解锁资格，纪念卡在“纪念卡”页以暗面等待翻开。

## 商店

当前有12件金币商品，另有4件默认样式。免费预览与六款特效装扮见[商店说明](SHOP.md)：

| 花盆 | 薄荷小花盆 80、云朵瓷花盆 120 | 独立盆型与配色，内置园艺素材的陶盆同步调色 |
| 背景 | 月色花园 120、樱色小院 150 | 独立场景插画，整本手账同步配色 |

商品购买后立即使用，永久拥有，再次装备不扣金币。默认样式可免费换回。花盆换色作用于小田插画和已审核内置园艺素材；通过实时绘制保留原文件、人物、植株、土壤与透明度，自选视频保持原样。预览免费，商店整页同步试穿，离开商店恢复已装备主题，不会扣金币或改动当前装备。金币还支持有独立编号的本地维护赠送，不计作出售或收获。

后续适合扩展：花园摆件、桌边小灯、纪念卡边框、收获篮、纸胶带和角色昵称牌。它们可以独立绘制并叠加展示，避免为换装重新生成整套动作。

## 花园演出

0.1.11内置11段透明花园视频和11张阶段图，8条主要生成原片已经齐备，当前无需继续生成。14个花园入口位于右键“动作 → 小花园”，也可在偏好管理预览。三种收获不另外制作采摘片，复用已有庆祝动作与果实入箱反馈。

手账内的固定演出区显示知栖、花盆、植株和水壶；对应小田的重复盆图隐藏，其他小田保留状态缩略图。点击植物缩略图可切换照料对象。0–2个浇水日为空土、3–5日长叶、6–9日开花、10日成熟。叶花期浇水只显示程序水滴，不播放空土视频，也不会抹掉植株。番茄4颗果、草莓3颗果、西瓜1颗果，与成片一致，每次收获仍只算一批。

演出只跟随成功保存的操作；播放、跳过和菜单预览不会增加进度、收获或金币。失败或停滞时回到实际阶段图，切页、跳过和收起手账会停止并释放视频。收获后复用人物庆祝，人物执行任务或处于番茄专注时遵守原有优先级。

自选花园动作优先于内置素材，移除自选动作会恢复内置版本。升级无需改写现有种植与金币存档。素材目录、全帧检查与接点限制见制作记录（仅本地制作归档：`../local-assets/notes/14-garden/README.md`）。少量生长接点仍保留生成重绘差异，继续使用已有素材。

**后续新生成视频单条最多15秒，优先复用。** 已有较长原片及后期剪辑保留，不重复生成。

## 金币与存档

金币、植物、收获、物品与交易流水统一保存在 `%APPDATA%\QiqiCodexPet\garden.json`。每次操作先验证完整状态，再写临时文件并替换主存档，同时保留上一份 `garden.json.bak`。只有保存成功才发布结果，失败不会消耗收获或扣发金币。

出售按收获编号去重，重复出售不能重复领金币；余额必须与全部交易流水一致，购买不能透支，客户端不能自定义售价。日期早于最近记录时停止新的种植与交易操作，避免回拨日期重复打卡。金币为离线养成数值；本地文件可自行备份，不作为真实账户或线上防作弊机制。

存档损坏或流水不一致时保护原文件并暂停交易，不自动归零。恢复前关闭桌宠，保留主存档和备份后再检查。金币存档及备份受 Git 忽略和发布审计保护，不进入源码与发布包。
