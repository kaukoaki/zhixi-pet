# 栖栖 · 角色动画演出原则

后续图生视频提示词采用更生动的日系 Q 版角色表演。以新版人物参考与固定提示词（仅本地制作归档：`../local-assets/workshop/docs/animation/README.md`）为准，保持人物身份、服装、小芽抱星胸章、编发挂饰和全身构图一致，同时让表情、眼神和手势随情绪充分变化。

- 设计简短的情绪递进，例如察觉 → 疑惑 → 想办法 → 重新振作。每一段有明确意图，动作之间自然衔接。
- 眼神先注意目标，头部再跟上，手势随后呼应。视线、眉毛、眼睑、嘴角和脸颊一起塑造表情，保留自然腮红与眼睛高光。
- 使用轻快起势、柔软缓冲、自然收势。适度加入歪头、轻耸肩、摊手、小握拳或短暂鼓腮，选择符合当前情绪的动作。
- 发梢、蝴蝶结尾带和披肩略晚于头肩运动，带一点柔软跟随和余动；呼吸、眨眼与轻微重心变化让停顿仍有生命力。
- 单次反应保持情绪推进；工作、待机等长循环保留细小表演，并检查首尾姿态与运动方向。中段用多种低幅度细节维持活力，避免机械地重复同一大动作。
- 固定人设、镜头与大小，控制足底漂移、裁切、胸标变形、手指增生和闪烁。用人物自身的表演传达情绪，保持桌面小尺寸下也清楚易读。
- 可按动作主题加入漫画注释，例如疑惑时的小问号、想到点子时的感叹号或小星星、亲昵时的爱心、困倦时的 `zZ` 气泡。它们配合角色的眼神和动作出现、停留、收起，允许适度夸张和幽默。每次优先选择一两种清楚的表达，不限制为纯人物演出。
- 气泡使用圆润轮廓、清楚描边与朝向角色的小尾巴；字符尽量简短。效果留在画布内的空白处，不挡脸、胸标和肢体，不用满屏闪光或长句。短符号可以独立于角色浮动，透明处理时必须保留这些有意设计的前景，区分水印与生成瑕疵。

提示词中的秒数与幅度是生成目标；收到成片后按实际内容取帧、检查边缘与播放衔接。情绪表演示例见 小小困惑提示词（仅本地制作归档：`../local-assets/prompts/06-error/prompt.txt`），漫画符号示例见 打个盹提示词（仅本地制作归档：`../local-assets/prompts/07-sleep/prompt.txt`） 和 欢迎回来提示词（仅本地制作归档：`../local-assets/prompts/08-return/prompt.txt`）。已经生成的动作提示词保留制作记录，新的创意用于后续动作。
