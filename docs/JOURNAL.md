# 知栖陪伴手账

右键选择“知栖陪伴手账”，或点击任务窗口标题栏的手账图标。也可通过插件要求打开陪伴手账。

默认打开[小花园与商店](GARDEN.md)，可以种植、浇水打卡、收获和购买装饰。原来的记录在“小记”页，纪念卡继续保留。

手账提供每日专注时光、完成的番茄数、七日足迹、连续陪伴天数、五种小表情和最多 600 字的小记。切换日期可回看记录；输入和心情变化约 700 毫秒后自动保存为本机草稿，恢复窗口或重启后仍能继续写。点击“收好这一天”才提交正式小记并计算相关纪念卡。

草稿按日期区分，加载另一日期时暂时禁止编辑，避免内容串到别的日子。正式保存期间的新输入会留作较新草稿；延迟到达的旧保存不会覆盖它。正常收起会先保存全部草稿，失败时保留窗口与文字；正常退出最多等待 3 秒完成草稿写入。

## 记录方式

- 从启用手账当天开始，历史累计统计保留，不推测过去的逐日记录。
- 按番茄钟实际消耗的计时记录专注，暂停和休息不计入。提前结束也保留已经专注的时间，只有完整完成一轮才增加一颗番茄。
- 跨越午夜的专注按日期分开；延迟收到完成事件时，番茄归入实际完成时间所在日期。以番茄钟计时为准，不检测用户的注意力或屏幕内容。
- 应用启动或跨天运行计为当天陪伴，同一天不重复计数。关闭期间的日期不补记；恢复时不把离线时间算作专注。
- 空闲、暂停或未打开手账时，也有独立日界检查，不依赖启动番茄钟才记录陪伴；长时间休眠后不补记缺席日期。
- 连续陪伴中断后重新计算，最长连续记录和已获得的纪念卡保留。
- 创建手账时记住本机时区，后续按该时区划分日期。

## 小小纪念卡

卡池扩展为 22 张知栖主题纪念卡。未解锁时只有相同的暗色卡背，不显示名称、图案、条件或进度。获得新卡后点击翻开，保存翻开状态；已翻开的卡片展示知栖形象，可以再次查看和导出。

番茄、草莓和西瓜分别在首次真正收获时带来一张新卡；成熟但未收获不会提前解锁。已经卖出的历史收获仍会被识别，获得的卡不会因出售、换装或连续陪伴中断而消失。已有卡和原来的获得日期保留，新增历史奖励以识别并解锁的当天记日。

点击并翻开已解锁的卡片，再点“保存纪念卡 PNG”，选择本地保存位置。卡片使用现有人物原画和本地绘制，不调用 AI、不额外生成视频，也不消费 Codex 额度。PNG 只包含卡片文案、获得日期与知栖形象，不包含小记或聊天内容。

## 保存与备份

个人文件为 `%APPDATA%\QiqiCodexPet\journal.json`，包含正式记录、逐日草稿与草稿版本，不上传或进入 Git/发布包。计时与陪伴的脏数据约每 15 秒保存，关键计时操作和日期变化也保存；草稿按防抖写入单独及时保存。备份时关闭知栖，复制这个文件即可。

若文件损坏，程序保留原文件并只读展示提示，避免覆盖旧记录；写入失败时提示尚未保存，不虚报成功。安装更新保留已有手账。
