## 知栖 Zhixi v0.1.18

Windows视频桌宠与Codex本地插件，支持额度窗口、任务窗口、番茄钟、陪伴手账、小花园与装扮。

### 普通用户下载哪个文件

下载 **`Zhixi-0.1.18-win32-x64.zip`**，右键“全部解压”，进入解压后的文件夹，双击 **`install.cmd`**。安装教程也随包提供，文件名为 **`INSTALL-WINDOWS.md`**。

需要 Windows 10/11 x64。完整安装需在终端中能运行 `codex` 并支持 `codex plugin`；额度和任务需登录Codex。普通运行不需要Node.js、Python或独立制作素材包。

安装完成后，在Codex新建一个聊天，输入“打开知栖桌宠”或 `$zhixi-pet`。

### 当前版本

- 37段现用动作统一使用小芽抱星胸章与白结、双紫晶、流苏编发挂饰。
- 覆盖日常互动、钱包反应、拖动分段、番茄钟与11段花园演出。
- 保留当前透明立绘、人设清单和后续动画提示词模板。
- 源码、当前实装素材和Windows安装包分开分发。

### 其他附件

- `Zhixi-0.1.18-current-media.zip`：供开发、打包或动画制作使用，只含37段当前实装视频与11张花园海报，不含原片、历史版本或逐帧制作QA。
- `Zhixi-0.1.18-source.zip`：精简源码。GitHub自动生成的Source code包同样属于源码，运行前还需同版本制作素材。
- 各ZIP对应的`.sha256`：下载校验文件。

### 更新与数据

更新时完整解压新Windows包并重新运行`install.cmd`。程序安装到`%LOCALAPPDATA%\Zhixi\app`，个人数据保存在`%APPDATA%\QiqiCodexPet`；安装升级保留设置、自选视频、手账与花园存档。
