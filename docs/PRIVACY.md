# 本地数据与权限

知栖不内置 API Key，不直接读取 Codex 凭据文件，也不上传视频、任务内容或设置到开发者服务器。

默认“去 Codex 发送”使用本机 `codex://new` 链接把文字与目录带入 Codex 输入框，由用户在 Codex 发送。“桌宠执行”与额度功能调用本机已经登录的 Codex CLI。额度读取请求账号类型和用量窗口；真实 CLI 任务仅在用户点击“桌宠执行”后启动，按所选工作目录与 CLI 权限运行。Codex 自身联网、账号与数据处理由其服务负责。

音乐文件随程序本地打包，播放不联网，不使用外部音乐流。“安静陪伴”勾选后立即停止音乐。

陪伴手账使用本地 `journal.json` 保存日期、番茄钟计时、会话去重编号、心情小记与纪念卡，不读取聊天内容或屏幕，不向模型发送小记。手账文件受 Git 忽略和发布审计保护。纪念卡 PNG 在本机绘制，只有点击保存并选好位置才写出文件，不包含小记或聊天内容。

未正式提交的小记和心情也可作为逐日草稿保存在同一个本地文件，恢复窗口或重启时读回。草稿带版本号以防旧请求覆盖新输入，只有明确保存正式记录才参与小记奖励计算。

小花园使用独立的 `garden.json` 保存植物、每日浇水、收获售价、金币流水、已购物品和装饰选择，每次操作保存并保留上一份 `garden.json.bak`。这些文件仅在本机，受 Git 忽略、发布审计与打包过滤保护；存档损坏时停止交易并保留原文件，不自动清空金币。种植和交易不调用模型或消耗 Codex 额度。

个人设置、视频副本、计时状态与诊断日志位于 `%APPDATA%\QiqiCodexPet`。播放日志不含账号凭据；用户分享日志前仍应检查其中的工作目录等信息。

`conversations.json` 在同一目录保存各工作目录的会话引用、最近问题、最近回复和轮数；完整上下文由本机 Codex 的会话存储管理。“新对话”创建新的引用，保留旧记录。该文件属于个人数据，受 Git 忽略和发布审计保护，不进入发布包。模型信息通过只读 `config/read`、`model/list`、`configRequirements/read` 取得，仅向界面提供模型、支持的思考强度和允许的执行选项，不转发提供商密钥或完整配置。

手动选择的模型、思考强度、执行权限和审批方式保存在个人 `state.json` 中，按工作目录区分，不修改全局 Codex 配置。“需要时审批”使用本机 app-server 交互连接，显示请求范围并等待用户决定，不自动批准；临时权限授权仅限当前轮。选择“不弹审批”使用 CLI 非交互执行，仍受选定执行权限约束。

源码和发布包不含用户配置、`.codex` 目录、账号数据、开发缓存或本机日志。插件安装前的 Codex 配置备份保留在本机 Codex 的 `backups/`，不写入仓库。

依赖和运行时下载只在用户执行安装辅助命令时发生。已安装桌宠不自动下载新角色或动作。
