# 新动作制作起点

后续图生视频统一使用[新版透明人物立绘](../../assets/character/qiqi-chibi-v5-knot-sprout.png)，完整尺寸与 SHA 见[人设清单](../../assets/character/appearance.json)。原图保留原始像素与透明度，不用旧 GPT 胸标图片作为新动作参考。

固定人设：银白渐薄荷发梢、紫眼睛、紧凑 Q 版身形、黑白金服装；胸口为“小芽抱星”胸章；侧编发的黑金蝴蝶结旁为白色盘结、两颗淡紫菱形宝石、细链与浅色流苏。挂饰固定在参考图正面朝向的画面右侧编发上，转身时跟随同一编发，避免镜像或漂到另一侧。

每次上传立绘后，将[固定人设提示词](character-lock.txt)与[动作模板](motion-template.txt)合用，只替换动作、情绪、时长、背景、镜头和循环方式。可直接从[问候示例](examples/greeting.txt)、[工作循环](examples/working-loop.txt)、[摸头回应](examples/pat-response.txt)或[转身检查](examples/turn-check.txt)开始。历史动作目录的旧提示词保留制作来源，其中的 GPT 胸标要求已经过时。

1. 先明确单次动作还是循环，填写节拍：起势 → 主动作 → 余动 → 回到起始姿态。桌椅、花盆、钱包等需连续时，额外提供同一场景接点图。
2. 上传新版立绘；固定人物比例、服装、胸章和编发挂饰。手、袖口和道具可以真实遮挡饰品；背面或远侧被遮挡时不强行显示正面图案。
3. 保持一镜到底、固定机位和足够画布边距；避免转场、叠化、双影和忽大忽小。若生成服务不支持 alpha，选择均匀纯白底后再按项目流程处理，不能把白底文件标成透明成品。
4. 原始导出放入新动作的 `source/`，透明 WebM、参数与检查放入 `processed/`。新动作按[素材规范](../../actions/ASSET-LAYOUT.md)建目录，不覆盖本次已审成品。
5. 验收原速、慢放和小尺寸显示；重点检查胸章、发饰、手指、遮挡、首尾循环和透明边缘。海报从最终编码视频首末帧提取，注册视频与海报时一起更新 SHA。

公开素材包只含37段成品和11张花园海报。原片对照、内嵌逐帧制作记录与下列复查命令仅用于保留了原片和QA的本地完整制作区，不包含在上传素材中：

```powershell
python scripts/audit-branding-library.py --output .cache/branding-review-next
```

输出包含全帧透明度、帧数、首末海报检查与风险抽样图；抽样图仍需人工确认。根目录“预览新动作.cmd”直接读取正式库，不另存一套重复视频。
