# 知栖使用指南

## 桌宠与 Codex

单击人物查看本机已登录 Codex 账号的实际额度，双击打开任务窗口，拖动可以移动人物。右键菜单提供人物大小、置顶、安静陪伴、动作点播及偏好设置。额度不可用时会显示提示，不用估算值代替。

任务窗口中的“去 Codex 发送”把内容带入 Codex，由你按 Enter 发送。“桌宠执行”在点击后按所选工作目录、模型和权限运行任务，可能消耗额度并修改文件。打开任务窗口本身不会执行任务。

安装插件后，可在 Codex 新聊天中输入“打开知栖桌宠”“打开知栖的番茄钟”“打开知栖陪伴手账”或“退出知栖桌宠”。安装和插件故障处理见 [Windows 安装教程](../INSTALL-WINDOWS.md)。

## 番茄钟

右键 → 番茄钟，或点击任务窗口的计时图标。可选 25、45、60 分钟，或自定义 1–180 分钟。开始后可以暂停、继续或结束；关闭计时气泡只隐藏窗口，不停止计时。

完成一轮后可手动开始 5 分钟休息或下一轮专注。提前结束保留已经专注的时间，但不增加完成次数；暂停和休息不计入专注。正常退出会暂停保存当前会话，重新打开后由你决定是否继续。

## 陪伴手账与纪念卡

右键 → 知栖陪伴手账。小记页可以查看专注时光、完成的番茄数、七日足迹和陪伴天数，选择心情并写最多 600 字的小记。

输入会自动保存本机草稿；点击“收好这一天”才提交正式小记。切换日期可回看记录。专注按番茄钟实际计时记录，不检测注意力或屏幕内容，关闭期间不补记陪伴日期。

纪念卡解锁后点击翻开，已翻开的卡可以再次查看或保存为 PNG。导出只包含卡片文案、获得日期和人物形象，不包含小记或聊天内容。

## 小花园与商店

花园有 3 个种植位，番茄、草莓和西瓜种子免费。点击“浇水打卡”为当天未浇水的植物浇水，每个种植位一天最多增长一次。累计浇水 10 个不同日期后成熟；漏打卡只暂停，不会枯萎。

成熟后收获，再选择出售。每批收获售价为 50–100 金币，在收获时确定，刷新不会重抽。三种植物首次收获分别解锁纪念卡，出售不会收回已获得的卡。

商店可以预览花盆、场景、手账纸和人物特效。预览免费，离开商店恢复已装备样式；点击兑换才扣金币并装备，已购买物品再次装备免费。金币仅为本地养成数值。

## 视频和动作

37 段内置视频覆盖日常互动、钱包反应、番茄钟、拖动分段和花园。右键 → 动作可以点播，偏好与动作管理可导入自选视频；移除自选花园动作后恢复内置版本。

不要直接重命名个人数据目录中的视频文件。程序通过动作绑定管理这些副本，手动改名可能导致无法播放。

## 更新与备份

更新时退出桌宠，解压新 Windows 包并运行 `install.cmd`，个人设置、自选视频、手账和花园保留。

备份前退出桌宠，复制整个 `%APPDATA%\QiqiCodexPet`。其中包括设置、动作绑定、视频副本、计时、手账和花园数据。若存档损坏或提示未保存，先保留原文件与备份，不要直接清空数据。更多说明见 [隐私与本地数据](PRIVACY.md)。
