## 哪些复用，哪些交给程序

- **播种复用**：同一颗种子入土的片段没有作物特征，可以服务三种作物。
- **空土浇水复用**：现有02仅用于空土期。已长叶或开花后，不再重播空土片；计划由程序在当前植物上显示水滴与叶片轻晃，取消旧15–20六条浇水视频的生成任务。
- **早期发芽短段复用**：03的前5秒已经剪出并完整解码核验，可作为草莓、西瓜共同前段。第149帧为两片光滑子叶，约6秒后已出现番茄锯齿叶，后半段保留番茄专用。叶片靠近人物发丝，不能用矩形覆盖旧植株来假装换种类。
- **待机复用**：各阶段的审核稳定尾帧配轻微程序摆动，不另生成每个阶段的待机视频，也不倒放生长或收获。
- **收获反应复用**：计划复用已有的“庆祝”或“完成啦”桌宠动作，花园只做真实果实入收获箱的反馈。取消旧06、10、14三条专门采摘视频，暂不追求人物真的摘下特定水果。
- **植物状态保留**：叶子、花和果实的不同状态由现有程序插画兜底。视频缺失时仍能打卡、成熟和出售，不强制用户补齐素材。

三种植物的主要生长素材已经齐备，当前待生成列表为空。播种、空土浇水、前5秒通用发芽继续复用；不再索取分阶段浇水、独立待机或三种专门采摘视频。后续工作是本地背景与定位处理，以及固定花园演出区、阶段水滴和收获反馈接入。

原30秒花果提示词与V2长方案保留作历史来源。未来若需要全新动作，单条提示词与生成设置均不得超过15秒，先考虑使用已有素材或程序动画完成。

0.1.11内置11段透明花园视频与11张审核阶段终态图，另以程序反馈和已有庆祝动作提供3种收获入口，共14个花园菜单项。`processed/*-v1.webm`为完成背景分离、底部标识清理和全帧alpha解码核验的成品；前面的`.scene.mp4`仍为保留的原背景剪辑预览，两者不要混淆。

- 手账小花园有固定演出区，完整显示知栖、盆、植株和水壶；播放及阶段静态展示时隐藏对应小田的重复盆图。点其他小田植物可切换查看。
- 0–2日空土、3–5日叶、6–9日花、10日成熟；叶花期浇水使用当前阶段图上的水滴，严格拦截空土片。三种成熟果数与已验收画面一致，仍按一批收获计价。
- 种植、浇水、成长与收获反馈只来自主进程成功保存的操作。播放、跳过、菜单预览和切页都不增加天数、金币或收获。
- 收获复用人物的庆祝/成功动作，并在花园显示果实入箱反馈；任务或番茄专注时继续遵守人物动作优先级。
- 失败、加载超时或视频停滞回到真实阶段图；跳过、切页、收起手账会释放视频与计时器。日常静态展示只保留微弱程序呼吸。
- 首次安装或升级均能读取内置场景；用户导入的花园动作优先，移除自选动作后回到内置版本，不改动原有植物和金币存档。
