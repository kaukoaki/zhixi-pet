# 01 · 挥手打招呼

这是待机循环之后的第二个动作制作包，对应 `greeting` 槽。现已收到用户生成视频并装配：720×720、24 fps、121 帧、约 5.04 秒。保留完整挥手过程，完成白底与鞋底投影分离后导出 `processed/greeting-v1.webm`，单次播放结束后返回已安装的待机循环。

点击桌宠或右键 →「动作」→「点击回应」→「打招呼」即可播放。源视频保存在 `source/greeting-source-01.mp4`，用户的 `<video-directory>\greeting.mp4` 未修改。以下保留原始制作说明。

## 输入与文件位置

- 共用待机参考图（仅本地制作归档：`../shared/idle-reference.png`）：已装配的透明待机视频首帧（720×720），推荐用这一张生成下一条动作，让人物大小、脚底位置和画风更接近实际待机。
- 共用角色定稿（仅本地制作归档：`../shared/character-design.png`）：原始角色定稿 PNG 的逐字节副本，保留已确认的形象与胸口金色 GPT 结形标志，作为设计备份。
- `prompt.txt`：上传参考图后可复制到豆包的图生视频提示词。
- `source/`：保存豆包下载的原始视频，例如 `greeting-source-01.mp4`，不要覆盖或改写原件。
- `processed/`：之后保存完成背景分离、人物对齐、透明编码的成品，例如 `greeting-v1.webm`。

具体入口、可选时长、比例与输出格式以当前豆包界面为准。若可选择，建议约 5 秒、与参考图一致的方形画幅。普通 MP4 需要后续检查和背景处理，上传透明 PNG 不保证导出视频拥有真实 alpha。

## 本条动作

开头约 0.5 秒保持与待机相同的自然站姿和细微呼吸；一只手从身体外侧抬到脸旁，轻柔挥两次；末段沿身体外侧放下，回到原站姿。全程脚底与镜头固定，手不挡脸、不遮住胸口标志，身体不走位。开头和结尾保持自然微动，避免静止定格后突然启动或停止。

人物脸型、紫色眼睛、银白渐青头发、编发蝴蝶结、黑白金服装、黑色短靴和 Q 版比例都应与参考图一致。胸口金色 GPT / OpenAI 结形标志保持六环交织形状，不能替换成星花装饰。

## 检查与接入

1. 对照参考图，检查角色和标志在每一帧都稳定，手指和肢体没有增生或变形。
2. 确认挥手有两次清楚的小幅来回，手和头发始终完整入画。
3. 核对开头与结尾的脸、双手、人物大小与脚底位置，使它能接在待机前后播放。
4. 将原视频保存在 `source/`，提供本地路径，继续完成透明处理和首尾衔接。
5. 处理完成后，把真实带 alpha 的 WebM VP9 成品导入 `greeting` /「打招呼」槽。单次播放结束返回默认待机，不占用独立的 `idle` 槽。

本目录中的制作资料不会自动生成媒体，也不会将尚未完成的挥手动作加入可播放菜单。
