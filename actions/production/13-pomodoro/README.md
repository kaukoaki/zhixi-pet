## 运行方式

右键「番茄钟 → 打开倒计时」，或任务弹窗右上角 ◷。25 / 45 / 60 分钟及自定义 1–180 分钟，暂停、继续、结束，完成后可手动开始 5 分钟休息。计时由主进程的绝对截止时间计算，收起窗口仍计时，拖动人物时倒计时跟随并避让屏幕边缘。

六段已可安装使用：开始一次 → 学习循环 → 每约 2.5–4 分钟随机播放督促、打盹或偷瞄中的一种 → 回学习循环 → 到时播放收工夸赞 → 回普通待机。多种小动作避免连续重复同一种。新包有独立六槽，不改变原来 16 个普通动作。真实 Codex 任务和拖动优先，暂停期间不触发小动作。右键番茄钟子菜单也可逐个点播六段。

先退出应用后，可用同一安全导入器：

```powershell
node scripts/import-action.cjs pomodoro-study actions/production/13-pomodoro/processed/pomodoro-study-v2.webm
```

或者在偏好与动作管理的「番茄钟 · 连续小剧场」中导入，目前六段均已有成品。
