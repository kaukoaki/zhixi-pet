# 00 · 第一条待机循环

待机视频现已收到并装配。源视频副本为 `source/idle-source-01.mp4`（720×720、24 fps、121 帧）；原始 `<video-directory>\待机.mp4` 保持不变。

透明成品为 `processed/idle-loop-v1.webm`：WebM VP9 alpha、720×720、24 fps、113 帧、约 4.71 秒。使用连通白背景分离去除白底与鞋底投影，并对首尾 8 帧作预乘透明颜色交叉过渡。真实解码确认 alpha 为 0–255，Electron 实际播放也验证透明和自动循环。

右键桌宠 →「动作」→「待机」→「自然待机 · 循环」可预览；「返回默认待机」可结束其他动作并回到此视频。以下保留原始制作资料，供后续修订。

## 输入资料

- 共用角色定稿（仅本地制作归档：`../shared/character-design.png`）：当前角色原始 PNG 的逐字节副本，来自 `assets/character/qiqi-chibi-v3-gpt.png`，没有裁切、换底、重绘或修改颜色。
- `prompt.txt`：可复制到豆包的图生视频提示词。
- `source/`：保存平台下载的原始视频，保留原文件，不用透明成品覆盖它。
- `processed/`：之后保存完成背景分离、人物对齐与透明编码的 WebM 成品。

以当前参考图为图生视频输入。若所用入口可以选择时长，第一条建议约 5 秒；具体按钮、时长与比例选项以你当前豆包页面为准，不需要为了匹配本文选择不存在的选项。若可保持正方形画幅，优先与参考图一致；否则需在后处理中统一画幅和脚底位置。

## 第一条只做这些动作

保持正面站姿，双脚不移位，身体原地轻呼吸。全程只自然眨眼一次，发梢和衣摆作极小幅度缓慢摆动，末段回到开始时的站姿、表情与发梢位置。不要挥手、转身、跳跃、出现道具或突然新增特效。

胸口的金色 GPT / OpenAI 结形标志是固定的服装图案：保持它的形状、位置和大小，不能变成星星、花朵或任意金饰；手和头发尽量不要遮挡它。银白渐青头发、紫眼睛、黑白金服装、黑色短靴和 Q 版比例必须稳定。

## 输出与透明处理

先下载并原样保存生成结果，例如 `source/idle-source-01.mp4`。不要仅靠扩展名或播放器黑底判断是否透明。普通 MP4 往往需要后期分离背景；透明参考图也不能保证输出视频有 alpha。

若生成结果新增了场景，先重做这一条。背景最好干净、单一、静止，便于之后处理；不要假定画面上的棋盘格就是透明通道，也不要把有色背景的视频直接导入当成透明成品。

通过背景分离后保留原画发丝与服装边缘，统一整条视频的人物尺寸和脚底基线，编码为真实带 alpha 的 WebM VP9，例如 `processed/idle-loop-v1.webm`。保留平台输出的实际运动帧，不以重复帧冒充更高帧率。首尾循环与角色身份稳定比名义帧率更优先。

## 检查后再接入

1. 完整播放至少三轮，首尾没有明显跳姿、闪帧、亮度变化或脚底漂移。
2. 对照 共用角色定稿（仅本地制作归档：`../shared/character-design.png`）：脸、发色、眼睛、衣服和胸口 GPT 标志没有变形或换样。
3. 在深、浅两种背景检查头发和裙边，没有残留背景或明显黑白边。
4. 在桌宠实际大小下查看，人物没有忽大忽小，动作自然清楚。
5. 双击桌宠打开小任务窗，进入齿轮设置，导入到独立的「默认待机」入口。不要占用 `greeting` 或其他十个动作槽。

待机成品通过后，再继续制作 `greeting`。原视频、透明成品和已导入的应用副本分别保存，方便后续比较与修订。
