# 钱包版本

所有已生成版本按同一规则保存：每个版本独立目录，内含 `source/` 原片、`processed/` 透明成品及处理/检查记录、`prompt.txt` 和说明。人物参考共用上层目录文件，不重复复制。

| 目录 | 动作 ID | 状态 |
| --- | --- | --- |
| `../` | `wallet` | 普通查看，已安装 |
| `01-abundant/` | 未注册 | 额度充足提示词，尚无对应视频 |
| `02-careful/` | `wallet-careful` | 省着点用，已生成并接入 |
| `03-low/` | `wallet-low` | 只剩一点点，已生成并接入 |
| `04-empty/` | `wallet-empty` | 空空的，已生成并接入 |
| `05-recovering/` | `wallet-wait` | 等一会就好，已生成并接入 |

`manifest.json` 是四个新增版本的可移植路径与验收索引；全动作索引位于 `actions/catalog.json`。旧的五个平铺 TXT 已归入各版本的 `prompt.txt`，内容保留。

默认路由：>50% 普通查看；21%–50% 省着点用；1%–20% 只剩一点点；0% 空空的；0% 且所有阻塞窗口均在未来 30 分钟内重置，等一会就好。优先使用页面展示的 Codex 总额度窗口，Plus 同时考虑五小时与周窗口，Pro 系列只使用周窗口。未知、过期、查询失败或没有总额度的多模型分桶时保持普通查看。

视频里没有真实金额或套餐名称，页面额度继续读取当前账号。后台轮询不播放动作，任务期间不打断工作动画；关闭弹窗、拖动、更新查询会取消过时的待播放结果。
